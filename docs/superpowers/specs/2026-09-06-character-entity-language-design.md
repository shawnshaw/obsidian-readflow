# 人物与其他实体术语设计

## Interaction Thesis

整理摘录时先让用户判断“是否需要持续记忆与建立关系”。需要则标记为人物；否则作为其他实体保留上下文。

## Information Map

- 人物：姓名列表，进入当前书的人物名册、档案与关系图谱。
- 其他实体：地点、组织、概念、事件，保留在摘录卡片和搜索中。
- 人物工作台：继续允许手动新增人物、补档案、建立无证据或有证据的关系。

## State Map

- 默认：人物字段在前，其他实体在后，说明各自用途。
- 空人物：人物工作台的空状态引导填写“人物”，而非旧实体格式。
- 历史摘录：数据不迁移，继续沿用兼容逻辑。

## Scope

只调整用户可见术语、顺序、空状态和示例。`entities`、`characters` 的数据字段和已有数据保持不变。
